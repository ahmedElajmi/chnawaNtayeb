Vérification responsive — de vraies fenêtres

Contrairement au sélecteur « Cadre » des autres pages (qui ne fait que resserrer le contenu), chaque iframe ci-dessous est un document réel de 320 / 375 / 768 px de large : les media queries s'y déclenchent, la disposition change réellement (barre basse mobile ; colonne latérale à ≥ 1024 px ; grilles 2/3/4 ; filtres feuille→colonne) et rien ne peut « élargir la page ». Défilez horizontalement pour voir les fenêtres de chaque page.

⚠ Les iframes sont des documents séparés : les bascules de cette page n'affectent pas leur contenu. Pour changer de direction/thème/langue dans une iframe, utilisez ses propres contrôles (masqués en mode embed — testez la page en direct pour les variantes ; la revue navigateur peut aussi redimensionner la fenêtre elle-même).
